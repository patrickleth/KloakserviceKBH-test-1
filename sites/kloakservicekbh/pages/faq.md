  Velkommen til vores FAQ-side, hvor vi samler svar på de ofte stillede spørgsmål om kloakrensning, vedligeholdelse og priser. Her finder du konkrete svar, der kan hjælpe dig med at forstå, hvad du kan forvente, når du har brug for professionel kloakservice. Svarene er udarbejdet med udgangspunkt i vores mangeårige erfaring som autoriseret kloakmester – så du kan trygt og nemt finde de informationer, der er vigtige for dig.

faq:
  - { q: "Hvad koster det at få renset din kloak?", a: "Prisen afhænger af kloakkens tilstand, adgangsforhold og den nødvendige service samt tidsforbrug. En standard rensning ligger typisk i prislejet ca. 1500-1600 kr. pr. time. Se vores priser. Erfaringen viser, at en hurtig rensning kan spare dig for større problemer på længere sigt. For en grundig gennemgang kan du læse mere om vores kloakrensning." }
  - { q: "Hvad koster kloakservice?", a: "Kloakservice dækker alt fra rensning (sug/spul) og inspektion til mindre reparationer. Vi oplever ofte, at en samlet service ligger et sted mellem ca. 1600-2000 kr. pr. time. Prisen fastsættes ud fra opgavens omfang og eventuelle særlige forhold. Du kan finde flere detaljer om vores priser på siden for kloakservice priser." }
  - { q: "Hvad koster en kloakmand i timen?", a: "En erfaren kloakmand i København arbejder typisk for mellem 500-800 kr. i timen. Du kan se vores konkrete priser her. Timeprisen kan variere afhængig af, om det er en akut opgave, eller om der er særlige udfordringer, der kræver ekstra indsats. Prisen afhænger også af om du skal have besøg af en kloakmester, rørlægger eller slamsugerchauffør etc." }
  - { q: "Hvor ofte skal man rense sin kloak?", a: "For at forebygge større problemer anbefales det at få renset kloakken hvert 2-3. år. I husstande med intensiv brug eller ældre systemer kan en hyppigere vedligeholdelse være en fordel. Regelmæssig inspektion kan identificere potentielle problemer, før de udvikler sig. For mere information om vedligeholdelse, se siden om stoppet kloak." }
  - { q: "Hvordan renser jeg min kloak?", a: "Det anbefales at overlade kloakrensningen til professionelle, da korrekt udstyr og ekspertise er afgørende for en grundig og sikker rensning. Vores team benytter blandt andet mekanisk rensning, højtryksspuling og tv-inspektion – teknikker, der dokumenteret sparer tid og penge. Læs mere om processen på vores side for tv-inspektion." }
  - { q: "Hvad koster kloakspuling?", a: "Kloakspuling er en effektiv metode til at fjerne genstridige aflejringer, og prisen ligger typisk mellem 1500-1600 kr. Se vores priser. Afhængig af tidsforbrug, opgavens omfang og kloakkens tilstand sikrer vi en målrettet indsats, der genopretter systemets funktion. For yderligere information om spuling, se vores side for kloakspuling." }
  - { q: "Kan afløb tåle kogende vand?", a: "Som udgangspunkt ja, dog anbefaler vi at få renset professionelt ved gentagende forstoppelser. Se mere under stoppet afløb på vores side." }
  - { q: "Hvorfor lugter mit hus af kloak?", a: "Kloaklugt i hjemmet kan indikere tilstopninger, utætte rør eller problemer med vandlåsen. Vores erfaring viser, at en systematisk inspektion – for eksempel via tv-inspektion – hurtigt kan identificere årsagen, så den rette løsning kan iværksættes. En rettidig indsats kan forhindre større skader og ubehagelige lugtgener." }
